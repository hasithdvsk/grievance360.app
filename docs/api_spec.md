# 📋 Grievance360 API Specification

Base URL: `http://localhost:8000/api/v1`

---

## 1. Health Probe

### `GET /api/v1/health/`
Checks database, redis, and NLP engine connectivity.

**Response (200 OK):**
```json
{
  "status": "healthy",
  "timestamp": "2026-10-23T10:41:00.123456Z",
  "services": {
    "database": "connected",
    "redis": "connected",
    "nlp_pipeline": "ready",
    "engine": "SentenceTransformer (all-MiniLM-L6-v2)"
  }
}
```

---

## 2. Complaint Registration & Dynamic AI Triage

### `POST /api/v1/complaints/register`
Accepts complaint details, embeds text using SentenceTransformer, routes to AICTE Bureau, assigns dynamic priority & SLA deadline, checks for duplicate complaints, and persists to PostgreSQL.

**Request Body:**
```json
{
  "title": "Senior hostel residents imposing physical roll calls and verbal abuse",
  "description": "Senior students in Hostel Block C are threatening first-year students with physical violence and ragging during midnight hours.",
  "complainant_role": "STUDENT",
  "complainant_email": "student.victim@example.org",
  "complainant_phone": "+919811223344",
  "institution_aicte_id": "1-10001001"
}
```

---

## 3. Complaint Tracking & Audit Timeline

### `GET /api/v1/complaints/track/{complaint_id}`
Fetches detailed complaint status, institution details, assigned bureau, SLA deadline, and complete chronological audit log timeline.

---

## 4. ReportLab Action Taken Report (ATR) PDF Exporter

### `GET /api/v1/complaints/{complaint_id}/export-atr`
Generates and streams an official, digitally signed Action Taken Report PDF with SHA-256 verification hash and complete chronological audit action table.

---

## 5. Executive PostGIS Analytics Overview

### `GET /api/v1/analytics/overview`
Returns top 10 geospatial hotspot regions, bureau resolution velocity, and critical breach counts.

---

## 6. Multilingual Translation & Voice Note Ingestion

### `GET /api/v1/multilingual/languages`
Lists all supported regional Indian languages: Telugu (`te`), Tamil (`ta`), Hindi (`hi`), Marathi (`mr`), Bengali (`bn`), and English (`en`).

### `POST /api/v1/multilingual/submit-voice`
Accepts multipart audio file uploads (.mp3, .wav, .m4a), transcribes via Whisper, translates regional Indian text to English via M2M100/IndicTrans2, and registers the complaint into the AICTE triage pipeline.

**Multipart Form Parameters:**
- `audio_file`: binary audio data
- `complainant_email`: `student@example.org`
- `complainant_role`: `STUDENT`
- `institution_aicte_id`: `1-10001001`
- `source_language`: `auto` / `hi` / `te` / `ta` / `mr` / `bn`

### `POST /api/v1/multilingual/translate`
Translates complaint updates, directives, or Action Taken Reports into regional languages.

**Request Body:**
```json
{
  "text": "IN_PROGRESS: Action is being reviewed by Nodal Officer.",
  "target_language": "hi",
  "source_language": "en"
}
```

**Response (200 OK):**
```json
{
  "original_text": "IN_PROGRESS: Action is being reviewed by Nodal Officer.",
  "source_language": "en",
  "target_language": "hi",
  "target_language_name": "Hindi",
  "translated_text": "कार्रवाई प्रगति पर है। नोडल अधिकारी द्वारा समीक्षा की जा रही है। (IN_PROGRESS)"
}
```

## 7. WhatsApp & Telegram Bot Webhook Integrations

### `POST /api/v1/bot/whatsapp`
Twilio WhatsApp Webhook endpoint for citizen self-service and grievance tracking.

**Headers:**
- `X-Twilio-Signature`: HMAC-SHA1 signature generated by Twilio using `TWILIO_AUTH_TOKEN`.

**Form Parameters:**
- `Body`: Message text string (e.g. `STATUS GRV-2026-00001` or `FILE <Description>`).
- `From`: User WhatsApp phone ID (e.g. `whatsapp:+919876543210`).
- `To`: AICTE Twilio Phone Number.

**Response:**
Returns standard XML TwiML `application/xml`:
```xml
<?xml version="1.0" encoding="UTF-8"?>
<Response>
    <Message>🏛️ AICTE Grievance360 Update ...</Message>
</Response>
```

**Commands Supported:**
- `STATUS <TicketID>`: Queries database/Redis for live status, bureau, priority, and remaining SLA hours.
- `FILE <Description>`: Triggers sentence-transformers AI classification, duplicate detection, creates complaint in PostgreSQL/audit logs, and returns tracking ID.
- `HELP`: Returns guidance on bot commands.

---

### `POST /api/v1/bot/telegram`
Telegram Webhook router receiving JSON update payloads.

**Headers:**
- `X-Telegram-Bot-Api-Secret-Token`: Optional webhook verification secret matching `TELEGRAM_BOT_SECRET`.

**Request Body (Telegram Webhook JSON):**
```json
{
  "update_id": 12345678,
  "message": {
    "message_id": 101,
    "from": { "id": 987654321, "first_name": "Hasith", "username": "hasith" },
    "chat": { "id": 987654321, "type": "private" },
    "text": "/status GRV-2026-00001"
  }
}
```

**Response (200 OK):**
```json
{
  "ok": true,
  "method": "sendMessage",
  "chat_id": 987654321,
  "text": "🏛️ *AICTE Grievance360 Live Status*\n🎫 *Ticket ID:* `GRV-2026-00001`...",
  "parse_mode": "Markdown",
  "action": "STATUS_CHECK_SUCCESS"
}
```

**Commands Supported:**
- `/status <TicketID>` or `STATUS <TicketID>`: Instant status, bureau, priority, and SLA remaining lookup.
- `/file <Description>` or `FILE <Description>`: AI triage, auto-bureau routing, SLA calculation, and database registration.
- `/start` or `/help` or `HELP`: Interactive help menu.

---

### `POST /api/v1/bot/chat`
Interactive in-app AI assistant supporting conversational queries, STATUS lookups, and instant FILE grievance triage.

**Request Body:**
```json
{
  "message": "STATUS GRV-2026-00001",
  "conversation_id": "session-12345"
}
```

**Response (200 OK):**
```json
{
  "reply": "### 🏛️ AICTE Grievance Live Status\n- **Ticket ID:** `GRV-2026-00001`\n- **Status:** `IN_PROGRESS`\n- **Assigned Bureau:** **Anti-Ragging Bureau**...",
  "action_type": "STATUS",
  "metadata": {
    "tracking_id": "GRV-2026-00001",
    "status": "IN_PROGRESS",
    "bureau": "Anti-Ragging Bureau",
    "priority": "CRITICAL"
  }
}
```

**Action Types:**
- `STATUS`: Response from ticket status verification.
- `FILE`: Automated ticket generation with AI bureau and dynamic priority classification.
- `INFO`: Informational guidance and quick-start instructions.
