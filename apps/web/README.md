# 🌐 Grievance360 Web Application

Citizen portal and executive analytics dashboard built with **Next.js 14 (App Router)**, **Tailwind CSS**, **Framer Motion**, **Lucide-React**, and **Recharts**.

---

## ⚡ Tech Stack

- **Next.js 14**: Server Components, streaming SSR, dynamic layouts
- **Tailwind CSS**: Utility-first styling with dark-mode CSS custom properties
- **Framer Motion**: Micro-interactions, animated metric transitions, route animations
- **Lucide-React**: Featherweight modern iconography
- **Recharts**: Responsive SVG-based charts for SLA and velocity reporting

---

## 🚀 Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Configure Environment
Copy `.env.example` to `.env.local`:
```bash
cp .env.example .env.local
```

### 3. Run Development Server
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
